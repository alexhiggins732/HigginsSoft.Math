# High-Level Overview of the Quadratic Sieve Algorithm

The Quadratic Sieve is a general-purpose integer factorization algorithm that efficiently factors large composite numbers (especially those up to around 100 digits). It combines techniques from number theory, sieving, and linear algebra.

## 1. Preprocessing and Factor Base Selection

- **Objective:** Factor the composite number `n`.
- **Steps:**
  - **Compute the Approximate Square Root:**  
    Calculate an approximation of `sqrt(n)`; this value is used as a starting point for generating quadratic residues.
  - **Select the Factor Base:**  
    Choose a set of small primes for which `n` is a quadratic residue. This set, known as the *factor base*, is later used to factor the values generated by the quadratic polynomial.

## 2. Generating Quadratic Residues

- **Define the Polynomial:**  
  Use the polynomial:
  
      Q(x) = (x + floor(sqrt(n)))² - n
  
- **Goal:**  
  As `x` varies over a chosen interval, the values of `Q(x)` are expected to be "almost" perfect squares.
- **B-Smoothness:**  
  Identify those values of `Q(x)` that factor completely over the factor base (i.e., they are *B-smooth*).

## 3. Sieving Process

- **Technique:**  
  Apply a sieving method (similar to the Sieve of Eratosthenes) to efficiently scan for values of `x` where `Q(x)` is B-smooth.
- **Record Factorizations:**  
  For each `x` that produces a B-smooth `Q(x)`, record its factorization in terms of the primes in the factor base.

## 4. Linear Algebra and Finding a Dependency

- **Exponent Vectors:**  
  Represent each smooth number as a vector of exponents modulo 2 corresponding to the factor base primes.
- **Matrix Formation:**  
  Assemble these binary vectors into a matrix.
- **Dependency Search:**  
  Use Gaussian elimination (or another method over GF(2)) to find a nontrivial linear dependency among these vectors. This dependency indicates that the product of the corresponding `Q(x)` values forms a perfect square.

## 5. Constructing the Factorization

- **Form the Equation:**  
  Multiply the selected `Q(x)` values together to form a perfect square, while simultaneously multiplying the corresponding `(x + floor(sqrt(n)))` values.
- **Modular Square Relationship:**  
  This leads to an equation of the form:
  
      a² ≡ b² (mod n)
  
- **Extract a Factor:**  
  Compute `gcd(a - b, n)`. A nontrivial result will yield a factor of `n`.

## Conclusion

The Quadratic Sieve leverages the interplay between smooth numbers and linear algebra to efficiently factor composite numbers. Its combination of mathematical insight and computational techniques makes it one of the fastest general-purpose factorization algorithms for numbers of moderate size.

# Parameter Selection for the Quadratic Sieve

For a composite number \(N\) of \(b\) bits, we have \(\ln N \approx b \ln 2\). Two key parameters in the quadratic sieve are:

1. **The factor base bound \(B\)** (which in turn determines the number of primes in the factor base)  
2. **The sieve interval \(L\)** (the length over which we search for smooth values)

## 1. Factor Base Bound and Number of Primes

A common heuristic is to choose the factor base bound as

\[
B = \exp\Bigl(\sqrt{\ln N \, \ln \ln N}\Bigr).
\]

Since the number of primes up to \(B\) is given approximately by the prime number theorem as

\[
\pi(B) \approx \frac{B}{\ln B},
\]

the **optimal number of primes** in the factor base is roughly

\[
|F| \approx \frac{\exp\Bigl(\sqrt{\ln N \, \ln \ln N}\Bigr)}{\sqrt{\ln N \, \ln \ln N}}.
\]

In terms of \(b\) (since \(\ln N \approx b \ln 2\)), this becomes

\[
|F| \approx \frac{\exp\Bigl(\sqrt{b \ln 2 \, \ln (b \ln 2)}\Bigr)}{\sqrt{b \ln 2 \, \ln (b \ln 2)}}.
\]

## 2. Sieve Interval

The goal of the sieve is to collect slightly more relations than the size of the factor base, typically about \(|F| + \Delta\) (with \(\Delta\) a small overhead, say 5–10 extra relations).

The probability that a typical value \(Q(x)\) (which is roughly of size \(N\)) is \(B\)-smooth is given asymptotically by the Dickman–de Bruijn function \(\rho(u)\), where

\[
u \approx \frac{\ln Q(x)}{\ln B} \approx \frac{\ln N}{\ln B} \approx \sqrt{\frac{\ln N}{\ln \ln N}}.
\]

Thus, the expected number of \(B\)-smooth numbers in an interval of length \(L\) is roughly

\[
\text{Expected relations} \approx L \cdot \rho\Bigl(\sqrt{\frac{\ln N}{\ln \ln N}}\Bigr).
\]

To obtain approximately \(|F|\) relations, one may choose

\[
L \approx \frac{|F|}{\rho\Bigl(\sqrt{\frac{\ln N}{\ln \ln N}}\Bigr)}.
\]

Because \(\rho(u)\) is not given by a simple closed-form expression, many practical implementations set the sieve interval as a small constant multiple of \(B\). A common practical choice is

\[
L \approx k \, B, \quad \text{with } k \approx 3 \text{ to } 5.
\]
